# 💻 Luis Munoz — Personal Portfolio Website

This is my personal portfolio website, built to showcase who I am, my skills, and the projects I’m working on as a front-end developer.

🔗 **Live site:**  
https://luismunoz25.github.io/portfolio-site/

---

## 🧠 About the Project

This portfolio was built from scratch using **HTML, CSS, and JavaScript**.  
The goal was to create a clean, responsive, and interactive site that reflects my personality while demonstrating real front-end fundamentals.

The site includes:
- A responsive navigation system (desktop + mobile)
- Light / dark theme toggle
- A typewriter text animation
- A projects section
- Contact and social links
- Custom fonts and icons

---

## 🛠 Technologies Used

- **HTML5** — semantic structure
- **CSS3** — layout, responsiveness, animations, dark theme
- **JavaScript (Vanilla)** — interactivity and UI behavior
- **Git & GitHub**
- **GitHub Pages** — deployment
